# 최신 역 모델 v7 복원

두 `.part01`, `.part02` 파일은 **하나의 Blender 파일을 바이트 순서대로 나눈 무손실 보존본**이다. 둘 다 받은 뒤 같은 폴더에서 다음을 실행한다.

```sh
python restore.py
```

Python 표준 라이브러리만 사용하며, 각 조각과 전체 파일의 크기·SHA256을 manifest와 대조한다. 검증이 성공하면 `Uijeongbu_Station_v7.blend`가 생성된다. Blender 5.2.4 LTS에서 재열기 검증했다.

서측 캐노피·계단·유리와 루버, 기존 내관·외관·철도·수목·밤 조명을 포함한다. 시 전체 윤곽은 `../city/Uijeongbu_City_Outline.blend`에 같은 좌표계로 별도 보존되며 웹에서는 하나의 공간으로 함께 표시된다. 치수·각 점포의 현재 외관을 모두 실측 복원한 완성본은 아니다.
