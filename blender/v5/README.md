# 최신 5차 Blender 원본

최신 파일은 이 폴더의 두 조각으로 무손실 보존합니다. GitHub 연결 도구의 요청 본문16MiB 한도 때문에 분할했으며 형상·텍스처를 삭제하지 않았습니다.

이 폴더 전체를 내려받고 실행:

```sh
python restore.py
```

`Uijeongbu_Station_v5.blend`가 생성됩니다. 조각별 및 완성 파일 SHA256을 자동 검증합니다. Blender5.2.4 LTS로 열 수 있습니다. 별도 패키지 설치는 필요 없습니다.

저장소 루트 `Uijeongbu_Station_v1.blend`는 이전 4차 호환 스냅샷입니다. 최신 웹 배포는 `web/assets/station.glb.gz`를 빌드 시 무손실 복원한 5차 모델입니다.
