## 조건 및 적용 방식
공식 페이지는 무료 다운로드·자유사용을 안내하며 판매·유상양도·무단배포를 금지한다. 공식 페이지에서 웹폰트 파일 재배포를 별도로 허용하는 상세 조항은 확인하지 못했다. 외부 요약 사이트의 허용 표를 공식 허락으로 단정하지 않았다.
이번 결과는 글꼴 파일을 웹에 올리는 방식이 아니라 세 역명 사인의 글자 윤곽을 Blender 메쉬로 적용했다. 해당 KORAIL 폰트 데이터블록은 메쉬 변환 후 제거했으며 원시 TTF는 결과 Blender에 pack하지 않았다. 공식 신형 폰트는 참고 확보만 했고 기존 간판에 자동 대체하지 않았다.

## 검증 및 범위
사진 https://hhk2001.tistory.com/8063 의 출입구 간판을 직접 대조했다. 구형 코레일체 적용 대상은 Entrance Korean, East station rooftop sign, 의정부역 sign. 기존 너비를 유지한 균일 스케일 조정. 모든 글리프를 메쉬로 변환했다. 영문·도로명·다른 브랜드 간판은 변경하지 않았다. 간판 전체 크기/자간과 현장 위치를 실측한 결과는 아니며 웹 배포 완료는 아니다.
