# v15 역사 하부 통로의 오분류 교정

## 출처와 실제 확인
- 2025-03-23 방문사진 23, 게시 2025-04-07: https://zenith2.tistory.com/15862539
- 2012 해안건축 준공 동측 전경: https://www.haeahn.com/upload/prompte/20150210154511755183.pdf (3쪽)
- OSM 원본 way1334917247: https://api.openstreetmap.org/api/0.6/way/1334917247 (버전2, 2024-11-25 편집)

두 사진을 직접 열어 역사 하부에 그늘진 개방 공간과 테라스 난간이 보이는 것을 확인했다. OSM 태그는 building:part=transportation / height=11 / layer=-1이다. layer=-1은 지물 간 상대적인 배치 태그이지 지하 1m를 뜻하지 않는다. 이 태그만으로 지상 3층의 규칙적인 창문을 만들 근거는 없다.

## 문제 정의와 처리
기존 자동 메시에는 해당 교통시설 띠 모양 공간에 3개 층의 창 구멍과 창문이 반복돼 있었다. 이를 역사 하부 전체가 일반 건물처럼 보이는 원인으로 판단했다. 사진에서 보는 북측 구간(y>80 상대좌표)만 변경했다. 남쪽 구간은 정확히 평면 클리핑하여 보존했다. 기존 테라스의 5.5m 상단을 유지하고 동일 위치의 중복 슬래브는 추가하지 않았다.

- 북측의 자동 창문 외피를 제거.
- 기존 테라스 아래에 개방 기둥 7개와 후퇴한 어두운 배경면을 배치.
- 테라스 외측에 얇은 수평 난간 3줄과 수직 난간 부재 97개를 배치.
- 새 메시를 재질별로 합쳐 3개 객체로 유지.

기둥 폭, 간격, 난간 높이, 상대 높이는 기존 모델과 사진 비례를 이용한 추정이다. 기둥 7개나 난간 97개가 실제 현장 개수라고 주장하지 않는다. 이는 분명한 창문 건물 오분류를 없애기 위한 국소 형태 근사다. OSM 정확도와 현장 준공도면 검증은 별개다.

## 검증 및 한계
원본 v14에서 스크립트를 재실행하여 누적 v15를 별도 저장하고 동일 카메라 렌더를 직접 확인한다. 도로의 실제 해발고도, 경사 각도와 교차로 연결은 이번에 조작하지 않았다. 잘못 추정한 도로를 만들기보다는 기존 평면 정보를 유지했고, 도로·테라스 높이 정합은 미완료로 남긴다. 실측 DEM·단면도 확보 없이 전체 지형 완성을 선언하지 않는다.

## 배포
GitHub 파일 저장 승인 요청을 다시 하지 않았으며 우회 업로드도 하지 않았다. 로컬 모델·렌더·연구자료만 Library에 보존한다. 사이트 반영은 별도다.

## 재검수 보정
첫 렌더에서 잘못된 3층 창문은 사라졌지만 상부 통로 너머 철로가 그대로 보여 사진의 어두운 후퇴 공간과 달랐다. 테라스 난간 뒤 3.5m 위치에 상부 후퇴 배경면을 추가하여 무근거한 관통 시야를 막았다. 이 깊이는 추정이며 실제 내부구조를 재현했다는 뜻이 아니다. 총 제거된 기존 외피 면은 195면이다.
추가 시각검수에서 높은 카메라로 상부 후퇴벽 위를 넘어 배경이 보였다. 후퇴 배경벽을 상대좌표 z=12m까지 연장해 외피 뒤로 숨겼다. 이는 렌더 관통 오류 방지용 배경 형상으로, 실제 역사 내부 벽높이를 의미하지 않는다.
