# 의정부역 동측 전면 시각 개선 v14

## 기준과 자료
기준 모델은 Uijeongbu_Station_v13c_east_corrected.blend다. 직접 열어 본 비교 사진은 https://zenith2.tistory.com/15862539 의 사진 23이다. 게시일은 2025-04-07이며 본문에 방문일 2025-03-23으로 명시되어 있다. 이를 2026 현재 사진이라 부르지 않는다. 보관된 2012 해안건축 자료는 준공 자료이며 현재 모습의 증거로 혼용하지 않았다.

## 문제 정의
v13c와 실제 동측 사진을 같은 면 기준으로 비교했다. 실제 사진의 흰 전면 외벽은 상단이 연속되는데 모델은 좌측 전면 일부가 계단식으로 낮았다. 사진에 없는 두 돌출 면이 우측 외벽에 남아 있었다. 간판은 모델에서 상대 비중이 컸다. 도시 전체의 단순화된 주변 건물, 하부 접근로와 백화점의 실루엣도 여전히 사진과 크게 다르다.

## 실행
공식 Blender 5.2.4 LTS를 다운로드하고 공식 SHA256 목록과 일치 확인 후 사용했다. 기존 설치 4.3.2는 파일 헤더를 읽지 못했다. 원본 파일은 수정하지 않고 새 파일에 저장했다.

1. 동측 전면 외피의 낮은 구간만 기존 최고 상단 상대좌표 27.998m까지 패널로 연속시켰다. 구조체와 건물 풋프린트, 도로, 선로는 변경하지 않았다. 이는 사진상 실루엣 보정이지 측량에 의한 높이 확정이 아니다.
2. 동측 면 밖으로 나오는 North window interior backs의 잔여 면 2개를 제거했다.
3. 동측 전용 간판 두 객체를 각 중심 기준 0.84배로 축소했다. 크기 비율은 사진 기반 추정이며 현장 계측값이 아니다.

## 시각 검수와 수정 이력
첫 렌더에서 창문 절개로 분할된 짧은 패널 열도 상단 보완 대상으로 인식해 중첩 띠가 생겼다. 이를 발견하여 최고점 21m 미만인 분할 조각을 추가 대상에서 제외하고 원본에서 다시 실행했다. 따라서 첫 렌더는 완료 산출물로 쓰지 않는다. 최종 렌더를 다시 직접 열어 확인한다.

## 범위 및 미완료
이 결과는 동측 전면 국소 개선이다. 초극사실적 전체 도시 완료가 아니다. 실측 DEM 취득·높이 정합, 주변 건물 간판, 백화점/역 하부의 실제 차도와 통로 단차, 뒤편 범용 도시 메시의 형태는 추가 작업이 필요하다. 사진에서 보이지 않는 구조는 임의로 실측처럼 기록하지 않았다. 다른 카메라에서는 외피와 기존 낮은 구조체 사이의 상부 덮개가 필요할 수 있으므로 후속 다각도 정합 필요.

## 배포 상태
로컬 Blender 저장 및 렌더·재현 스크립트 보존만 수행. GitHub 저장 승인 요청을 재실행하거나 우회하지 않았다. 원격 main 병합과 Cloudflare 배포는 이 작업에서 하지 않았다. GitHub Actions 사용 없음.

최종 검수: 재렌더 파일을 직접 열어 첫 시도의 세로 중첩 띠가 사라졌고, 창 4개와 연속 상단·돌출 면 제거가 유지됨을 확인했다. 최종 추가 패널은 90면이다. 좌측 보완 면과 기존 면의 재질/광반응 차이가 약하게 보여 후속 균일화가 필요하다.
