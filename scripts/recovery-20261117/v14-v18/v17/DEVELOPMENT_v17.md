# v17 전경 우측 자전거 보관시설 두 동 오분류 교정

## 어떻게 문제를 특정했는가
v16 렌더에서 우측 전경의 큰 창문 건물이 역 진입부를 가렸다. 카메라 픽셀(1100,750), (1100,700), (1000,800)에 광선을 쏘아 충돌 객체를 검사했다. 세 점 모두 OSM building [1144299904]였다. 단순히 보기 싫어서 임의로 지운 것이 아니라 화면 객체를 원본 지도 지물과 대응시켰다.

## 원본 조회와 충돌하는 높이 정보
https://api.openstreetmap.org/api/0.6/way/1144299903
https://api.openstreetmap.org/api/0.6/way/1144299904
두 지물의 태그는 amenity=bicycle_parking, bicycle_parking=building, roof:shape=round, height=1, roof:height=1.5다. 2025-03-23 방문사진 https://zenith2.tistory.com/15862539 의 동측 전경에서 낮은 곡면 보관시설이 확인된다.

기존 모델은 두 시설을 각각 9.9m 기본높이의 다층 반복창 건물로 만들었다. 원본 용도와 지붕 형태에 반하므로 이 오분류를 교정했다. 다만 OSM height가 총높이라는 일반 의미대로라면 roof:height=1.5가 height=1보다 커서 모순이다. 따라서 height=1을 처마, roof:height=1.5를 지붕 상승분으로 잠정 해석하여 최고점2.5m를 만들었다. 현장 실측이나 공식 도면 높이라고 주장하지 않는다.

## 구현
기존 네 모서리 풋프린트와 긴 축, 폭을 보존했다. 일반 건물과 주변 범용 창문 메시를 제거하고 곡면지붕24면과 지지대60면을 각각 생성했다. 두 시설의 총 추가 객체는4개·총168면(각24+60)이다. 실제 받침기둥 개수·간격·재질은 사진비례에 따른 근사다.

## 검수
동일 카메라의 전후 렌더 외에 시선 높이2m의 비교용 카메라를 추가했다. 이는 사진 촬영 위치·렌즈를 정확히 역산한 카메라가 아니라 지상 시점에서 새로운 오류를 찾기 위한 보조시점이다. 원래 카메라는 보존했다.

## 남은 문제
역사 좌측 하부의 반복창은 별도의 교통시설 지물과 얽혀 있어 해당 개구부·통로 범위를 더 확인해야 한다. way1311394048 원본에서 min_height=6, height=20을 확인했으나 기존 모델의11~16.5m와 다르다. 이 태그만으로 전체 역체를 즉시 늘리면 다른 실루엣과 충돌하므로 이번에 변경하지 않았다. 도로 경사와 지하 진입부 실제 레벨도 미완료다.

## 보존 및 배포
누적 모델·렌더·원본XML·재현 스크립트 보존. GitHub 승인 요청 반복이나 우회, main 업데이트, 사이트 배포는 하지 않았다.


지상 시점 검수에서 v14 상부 보완 패널의 뒤가 비어 줄눈으로 하늘빛이 들어오는 흰 사각형 패치가 두드러졌다. 기존 내부공간을 새로 꾸미지 않고 보완 영역 뒤에 불투명한 한 면을 추가하여 빛샘을 줄이는 재검수를 진행했다.
최종 두 시점 렌더를 직접 열어 우측9.9m 블록이 낮은 곡면 쉼터로 바뀌고 역사 진입부를 가리던 오분류가 해소됨을 확인했다. 상부 흰 패치 빛샘도 줄었다. 다만 보완 패널 구간의 미세한 줄눈 광반응/앨리어싱은 남아 있어 이를 완벽한 외장 정합이라 표현하지 않는다.
