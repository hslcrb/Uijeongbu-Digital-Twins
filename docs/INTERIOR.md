# 의정부역 대합실 사진 기반 연구 모델

## 근거와 범위
2025년 3월 23일 방문 사진 17·18·21 세 장을 직접 보고 만든 내부 시각 연구 모델입니다. 회색 반사 타일, 금속 격자천장과 매입 사각등, 유리칸막이, 좌측 승차권기기, 파란 방향안내판, 노란 T자 점자블록, 개찰기, 계단과 양측 에스컬레이터의 형태를 관찰했습니다.
직접 확인한 사진 게시물: https://zenith2.tistory.com/15862539 (방문일 2025-03-23). 사진 출처와 원본 URL은 외관 저장소 `reference/RESEARCH.md` 및 조사 `blog-images.json`에 기록되어 있습니다. 사진을 텍스처로 복제하거나 재배포하지 않았습니다.

실측도면이 없어 너비·길이·천장높이, 세 사진 사이의 상대배치, 개찰구 수량, 계단 깊이와 위치는 시각 연구용 근사입니다. 현재 운영 동선·설비 위치·운행시간표로 사용하면 안 됩니다. 내부 모델 원점은 독립 좌표(0,0,0)이며 외관 지리좌표에 자동 정합한 것이 아닙니다. 사용자 지시에 따라 외관의 역사 출입구·층과 연결해 하나의 공간으로 통합해야 합니다. 생성 원점은 외관 제작자가 확인한 변환행렬을 적용할 작업 좌표입니다.

## 제작 및 검증
- `build_interior.py`: Blender 5.2 LTS Python 생성기.
- `Uijeongbu_Concourse_Study.blend`: 편집 가능한 실제 3D.
- `uijeongbu-concourse.glb`: 외관 통합용 중간 장면. 실제 광원은 GLB에 제외되어 웹 조명 필요.
- `interior-concourse.jpg`: 실렌더. 원본 사진이 아닌 모델 렌더.
- `validation.json`: 재현 실행 결과.

텍스트는 Noto Sans CJK Regular(SIL OFL)로 형상 변환했습니다. 광고·구체 시간표·사람은 현행성 검증이 없어 재현하지 않았습니다. 정적 메시는 재질별 병합하여 드로콜을 줄였습니다. 유리의 표현은 렌더러에 따라 달라집니다.

### 외관 연결
공식 문화도시의정부 FAQ는 `의정부역(3층 대합실)`과 4층 문화역을 구분합니다: https://ucf-uac.or.kr/web/main/bbs/faqs/list . 외관 제작자와 조율한 작업 변환은 `(2,57,11)`으로 남측 입구 local `(0,-15,0)`를 world `(2,42,11)`에 둡니다. 높이 11m는 외관 OSM 태그와 사진을 바탕으로 하는 추정이며 공식 층고가 아닙니다. `append_interior.py`를 사용해 하나의 외관 scene에 붙이고 출입구 연결과 충돌을 최종 검수해야 합니다.

### 시각 검수와 수정
첫 렌더에서 중앙 기둥이 점자 통로를 막는 문제가 보여 해당 가정 기둥을 제거했습니다. 안내판 글씨를 확대했고 점자 리브 높이를 낮췄습니다. 계단 시점에서 에스컬레이터가 바닥에 묻히는 결함을 확인해 바닥 개구부를 양측까지 넓히고 아래층 착지면을 만들었습니다. 유리는 원본 사진처럼 투명하게 보이도록 투과·거칠기를 조정했습니다. 최종 장면의 안내판 문구는 방향 표시 형상 연구이며 실제 운행 안내를 대체하지 않습니다.
