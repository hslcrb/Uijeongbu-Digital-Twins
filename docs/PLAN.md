# 의정부역 디지털 트윈 — 2026-11-16 작업 계획

## 모델링 원칙
- 빈 저장소에서 시작. 기존 README 및 공개 설정은 유지한다.
- Blender 4.3 재생성 가능한 Python generator, 편집 가능한 collection 구조.
- 원설계 사진에서 확인되는 백화점/역사 분리 매스, 세로 루버, 곡선 캐노피, 외부 계단/램프를 우선 구현한다.
- 지도 geometry가 확보되면 도로와 주변 footprints는 그 데이터로 작성한다. 미확인 높이·창호·점포는 추정으로 구분한다.
- 인증된 최근 간판만 현재 상호로 표기하며 오래된 광고를 현재 광고처럼 복제하지 않는다.
- 하늘/낮/해질녘/야간 조명 preset, collection instance 수목, 원거리 LOD를 제공한다.
- 무료 라이브러리 설치 여부를 실제 확인한다. 현재 기본 Blender에 수목 라이브러리가 없다. 직접 제작 자산은 외부 무료 에셋으로 표기하지 않는다.

## 검증
재생성 → .blend 재열기 → 낮/야간 render → 화면 검수 → 통계/출처 문서 → 마이크로커밋 → main 두 부모 병합.
실측 모델/완전한 현재현황/100% 포토리얼 완료를 검증 없이 주장하지 않는다.
