# 의정부역 외관 연구 모델 v1

## 재현 및 범위
Blender 5.2.4 LTS에서 `blender -b -t 8 --python scripts/build_scene.py` 실행. assets와 data는 저장소 상대 경로로 읽는다. 완성 도시의 실측 쌍둥이가 아닌, 사진과 OSM 기반 편집 가능한 외관 연구 첫 버전이다. 주변 지형은 평면 기준면이며, 사진과 지도에서 확인한 시민로 지하차도에 추정 깊이의 경사와 옹벽을 추가했다. 현장 측량이 아니다.

- 원점 경도127.046 위도37.738, 동쪽+x 북쪽+y, 단위m.
- OSM 건물494동, 역사9매스와 백화점13매스. OSM 자체도 현재 실측으로 보증하지 않는다.
- 높이244개는 층수 또는 기본값 추정. 각 건물 height_evidence 속성에 구분.
- 백화점 고층 갈색 패널/수직핀, 낮은 역사, 중간 곡선 유리 캐노피, 외부 주차램프는 해안건축 사진의 형상 해석이다. 세부 치수는 추정.
- 간판은 확인된 의정부역/SHINSEGAE 식별명만 사용했다. 당시 광고판/현재 입점 매장을 임의 복제하지 않았다. 꽃 형태는 공식 로고 벡터가 아닌 근사 형상이다.
- 기본 카메라와 광장/주차장 카메라3개. 프레임1 낮,120해질녘,240밤. 재질과 광원은 편집 가능하다.

## 최적화
반복 창문·금속 모듈을 재질별 배치병합. 건물 OSM 추적속성은 보존. 나무는 공유 mesh 인스턴스, 원경 LOD 컬렉션 별도. 실제 PolyHaven CC0 나무 가을 LOD2 12그루 적용. 이 수종은 한국 현장 수목으로 검증되지 않은 조경 근사다. 구형 나무를 나무로 주장하지 않는다. 텍스처256px 파생본을 pack했고 고해상도원본 provenance는 별도manifest에 기록한다.

## 자료 및 권리
지도 © OpenStreetMap contributors, ODbL 1.0 https://www.openstreetmap.org/copyright . data/map.osm은 해당 공간범위 다운로드이며 기여자 계정 메타데이터를 제거했다. 지도 파생 지오메트리의 DB조건은 ODbL을 따른다. 출처시점/사진 관찰은 reference/RESEARCH.md 참조. 외부 참고사진 원본은 저장소에 재배포하지 않았다.
PolyHaven tree_small_02는 CC0. 자세한 provenance와변형은 docs/TREE_ASSETS.md.
station-labels.otf는 Noto Sans CJK KR의 사용문자 subset, SIL OFL1.1. LICENSES/OFL.txt 포함.

## 남은 시각검증
현재 입점간판 전수조사, 각 외벽 창문 실측비율, 광장 실제 시설위치, 지형높이와 도로 교차부, 전체 범위 최신 사진대조가 남는다. 모델을 100% 동일·극사실 완성이라고 부르지 않는다. 배포사이트 설정은 원래 저장소에 없었고 새 호스팅/공개설정은 만들지 않았다.
