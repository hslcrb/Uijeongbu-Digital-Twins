# 서부 출입구 사진대조 v8 (v7에 추가)

## 관찰
- `old2014-3.jpg`, `old2014-4.jpg`를 직접 열어 확인. 낮은 진입구에는 평평한 유리처마가 먼저 있고 그 뒤가 경사 캐노피다. 주기둥은 사각이 아니라 굵은 원형 강관이며 상부 원형 횡관과 연결된다. 유리처마에는 가로·세로 격자가 모두 있다. 계단 외측 하부는 투명 난간 아래 막힌 회색 패널 벽이며 수직·수평 줄눈을 가진다.
- `pocket2025.jpg` 직접 확인. 같은 서측 연속 경사 캐노피와 막힌 회색 경사벽, 가는 보조기둥, 지붕 양방향 격자가 확인된다.
- 2014 사진의 상점명·출구표지·임시 광고와 사람은 현재 상태로 옮기지 않았다. 사진 당시 원형 기둥 재료·정확 치수가 2026년에 동일하다고 검증한 것은 아니다.

## 수정
- v7이 생략했던 지붕 세로바를 3개 접근부에 추가.
- OSM 지붕 평면의 하부 돌출 여유 안에 2m 수평 진입 유리처마 추가. 실제 길이 실측값 아님.
- 남서·북쪽 낮은 진입구 각2개 원형 주기둥 및 횡관/칼라 추가.
- 두 하부 접근 계단 외측에 회색 닫힌 경사벽과 패널 줄눈 추가.
- 원본 저장소/브랜치/기존 .blend 변경 없음. v7 위에서 별도 컬렉션을 추가하는 재실행 가능 함수 `refine_west_access()`.

## 배치 판단
기존 OSM 접근선의 위치를 유지했다. 좌표가 확인되지 않은 택시쉼터, 노란 파라솔, 원목스툴은 배치하지 않았다. 사진에 있는 것이 모두 정확하게 복원됐다는 주장이 아니다.

## 시각 검수
Cycles20 samples, 1400×1000. v7과 동일 카메라(-117,-5,16), look-at(-65,42,7),35mm. 출력 `west-v8.png`. 세부 부재는 확대해야 읽히며 전경 지면의 기존 종이처럼 겹치는 보행면과 상가 외관은 이번 모듈 범위 밖이다.
