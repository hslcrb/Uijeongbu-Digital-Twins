# v19 커튼월 모델 정적 충돌 갱신

최종 배포 GLB SHA-256: `ec4e0d5584dcb01375547c4d37adb2cfecfb467ee02657a3c3fc7e89d9321316`.

최신 철도 단일세계 main 8681ca7에서 최종 GLB 자체를 디코드하는 `rebuild-static-collision.mjs` 전체 파이프라인을 실행했다. 420개 타일, 구조 충돌면 918,291개, 비압축 타일 48,201,440바이트를 생성했다. 모델 변경과 bake 버전이 일치하며 새 타일은 커튼월 두께 변경을 포함한다.

실제 최종 GLB의 대합실 중앙통로·좌측 이동 회귀 PASS. 바닥 접촉 유지, 기존 방식 대비 경로 오차 0.5m 이내, baked 런타임 인덱스 재구축 및 폴백 프레임 모두 0. Node CPU 샘플 중앙통로 1252.3ms → 192.6ms, 좌측 556.2ms → 121.6ms. 브라우저 FPS 측정은 아니다.

34개 테스트 통과. 최종 v19 모델과 함께 빌드하여 420개 충돌 타일 복원 및 해시 일치를 확인했다. 이 변경은 충돌 assets와 검증 기록만 포함하며 모델 파일은 배포 담당의 변경과 함께 통합해야 한다. 구형 모델과 함께 빌드하면 의도적으로 기존 충돌 방식으로 폴백한다.

기존 계단 방향 외부 건물 벽 겹침은 유지되며 전체 층·플랫폼 연결을 보장하지 않는다. 동적 열차는 정적 bake 대상이 아니다. 브라우저/GPU 상호작용 검증을 수행했다고 주장하지 않는다.
