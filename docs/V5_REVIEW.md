# 5차 사진·거리시설·철도 디테일 개선

## 자료와 구현
- 2025-03-23 역 사진과 고각 외관 사진을 직접 대조해 동측 흰 타일벽/소수 정사각 창과 북측 긴 창띠를 다르게 구성했다. 타일 규격과 계조, 창띠 치수는 사진 기반 추정이다.
- 한화생명은 하나은행 공식 지점 주소(평화로516 한화생명빌딩1층)와 한화63시티 공식 건물 자료를 대조해 OSM1466029481에 연결했다. 10층 정보는 공식 자료를 우선했다. 기존 일반 건물과 그 주변 창문2016면을 제거한 뒤 갈색 유리 외관으로 교체했다.
- 실제 OSM 가로등28개, 신호기 앵커2개, 횡단 앵커8개, 나무보호틀35개를 적용했다. 도로명 시민로·평화로·신흥로는 지도에 존재하는 이름이며 표지판 설치 위치/크기는 추정이다. 신호등은 정적 표현이고 실제 신호운영을 재현하지 않는다.
- 가로등은 Blender 하향 조명으로 표현한다. 값은 렌더 설정이며 실제 소비전력/조도 측정치가 아니다.
- 철도 자갈은 외부 저작물 사진을 잘라 쓰지 않고 독자 절차적 이미지512px와24,821개 작은 돌 형상,11,744개 체결판을 배치했다. 정확한 개별 자갈 위치는 추정이다. 재질별6배치로 개별 오브젝트 폭증을 피했다.

## 시행착오와 검증
- 역사 옥상 글자의 기존 위치가 벽에서 떠 보이는 문제를 사진의 동측면 방향에 맞춰 조정했다. 첫 타일 검수에서 상부 매스가 무표현으로 남은 부분을 추가했다.
- 한화 교체 후 OSM 객체 수가516에서515로 바뀌어 기존 검증의 고정 수 assertion이 실패했다. 무조건 완화하지 않고, 한화 사진 대체 컬렉션 및 원래wayID 근거가 있을 때 정확히1개를 대체한 것으로 검사하도록 수정했다.
- 통합 모델의1790객체·무료수목12공유인스턴스·패킹 이미지·낮/석양/밤 키프레임을 재열기 검수한다. 외관·교차로·철도 렌더는 직접 열어 비교했다. 아직 모든 외관을 실측대로 재현한 모델은 아니다.

## 대용량 보존 경로
단일 Blender 파일은14,449,268bytes이며 base64 요청19,265,692bytes에서 GitHub 연결 도구가16MiB 본문 제한HTTP400을 반환했다. 형상을 제거하지 않고 파일을 두 조각으로 나눠 `blender/v5/`에 저장했다. `restore.py`는 각 조각과 전체 SHA256을 검증한 뒤 원본을 복원한다.

전체 파일 SHA256: `23e956af7c4e78bfdaef413893a7331b582537aa389791c80434c6185d762521`.

웹 GLB14,548,736bytes는 gzip8,115,543bytes로 무손실 저장한다. `build.mjs`는 이를 복원해 glTF 헤더·길이를 검증하고 기존 콘텐츠해시 파일명으로 배포한다. `npm run build` 성공 및 복원 전후 SHA256 `fde1fd20970937032f92c31d6a4b0fff40db4f52aad43a8b83826e8478d4e696` 일치를 확인했다. GitHub Actions는 추가하지 않았으며 Cloudflare native main 자동빌드 구조를 유지한다.

좌표를1mm 격자로 바꾸는 압축 실험은 용량 이득이 작아 최종본에 적용하지 않았다. 최종은 원래 좌표정밀도를 유지한다. 루트 `Uijeongbu_Station_v1.blend`는4차 호환 스냅샷이며 최신5차는 별도 폴더에 명확히 구분했다.

## 남은 한계
역사 하부 부속 매스와 주변 일반 건물의 상세 비례·실제 간판·조경 수종·철도 부품의 완전한 최신 전수조사는 미완이다. 도로명 표지 및 재료 계조의 추정은 실측 사실로 표현하지 않는다. 시 전체 데이터는 별도 타일 단계로 진행하며, 현재 역 모델과 중복하지 않는 좌표/범위 검증이 선행되어야 한다.
