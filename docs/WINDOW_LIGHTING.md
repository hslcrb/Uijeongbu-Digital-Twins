# 주변 창빛·투명 유리 연구

- 소스 관찰: [파이낸셜뉴스 2025-03-19 기사 사진](https://www.fnnews.com/news/202503192113443362), 뉴시스 DB 사진으로 실제 촬영일 미확인. 실제 사진을 열어 주변의 점등·소등 혼합, 차가운 창빛과 따뜻한 내부빛을 확인했다.
- **수치나 방 배치는 실측이 아니다.** OSM 건물 footprint와 기존 높이에 절차적 창 간격·내부 얕은 공간을 적용한 시각 연구다. 특정 실내 평면이나 점등 상태의 정확한 복원이 아니다.
- `scripts/building_lighting.py`의 `enhance_building_windows()`를 외관 생성 이후 호출한다. 기존 `12_Window_room_proxies` 컬렉션이 있으면 중복 실행하지 않는다. 수정본 재적용은 원본 생성부터 재실행한다.
- 기존 불투명 벽 앞에 창 사진을 붙이는 방식 대신 벽면을 창 구멍으로 분할하고, 0.03m 두께 유리·0.9m 안쪽 벽·상하좌우 내부 면을 만든다.
- 유리 앞/뒤 +0.04/+0.01m, 프레임 +0.055m, 내부 벽 -0.9m. 원벽과 공면 경쟁을 없앤다. 대형 도시 장면 GLB는 위치 양자화 20bits 이상을 권장한다.
- 시드 고정 점등, 324건물·16,459개 창·7,263개 점등. 7개 공유 재질 배치로 점등마다 독립 광원을 만들지 않는다. 원격 모바일 GPU 성능 실측은 아직 하지 않았다.
- `Room glow 0`, `Room glow 1`, `Room glow 2`: frame1 emission0 / frame120 0.63 / frame240 1.8. `Room glow 3`: 소등. 낮 프레임 GLB를 내보낸 뒤 웹 뷰어가 같은 재질명으로 밤 프리셋을 변경해야 한다.
- Blender Cycles 야경 렌더 직접 검사. 웹 WebGL 환경의 전체 실제 기기 검증과 구분한다.
