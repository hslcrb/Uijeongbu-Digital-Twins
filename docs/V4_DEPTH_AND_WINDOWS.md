# 4차 철도·야간 창·깊이 오류 개선

사용자가 보낸 WebGL 화면에서 도로 교차부의 회백색 줄무늬와 창문 잡점을 확인했다. 원본 모델의 같은 높이 도로 ribbon이 겹치고, 기본 Draco 좌표 양자화가 얇은 돌출 창면과 비슷한 단위이므로 두 원인을 함께 수정한다. 웹 카메라 깊이 버퍼 개선은 별도 담당이 병행한다.

- 1,825개 원본 평면 기록에서 Shapely 합집합 및 차집합을 계산했다. 도로/보행로/연석의 수평 면적을 상호 겹치지 않게 분리하고 각각 단일 배치로 저장했다.
- Draco 위치 20bit, 법선12bit. 전체 씬 크기 기준 좌표 손실을 줄인다. 실제 브라우저 여러 시점에서 추가 검증해야 한다.
- 사진·OSM 기반 3개 섬식홈, 105개 선로 구간, 5,872개 침목. 침목 간격·플랫폼 치수 및 표고는 모델링 추정. 실제 운행 정보나 측량 결과가 아니다.
- 324개 주변 건물은 평면 유리판을 붙이는 대신 벽에 창구멍·3cm 유리·0.9m 내부 깊이를 둔다. 16,459개 창 중 7,263개는 야간 점등하도록 구성했다. 이는 사진의 불규칙 점등을 참고한 절차적 근사로 개별 실제 방 배치·점등 현황이 아니다.
- 이전 내부 계단 위 후면 기둥의 떠 있는 부분을 제거하고, 외부 문을 통해 같은 대합실이 보이도록 조명을 보강한다.
- 글꼴 원본 파일뿐 아니라 Blender에 패킹된 글꼴도 교체한다.

렌더: day-v4.jpg / night-v4.jpg / plaza-v4.jpg. 검수용 Cycles 렌더로 낮·야경은24samples, 입구는64samples. 낮은 샘플의 노이즈와 실제 WebGL 깊이경쟁은 구별해야 한다. 현행 간판, 주변 모든 외관의 정확한 재료와 치수 등은 여전히 추가 조사 대상이다.

재생성 순서: base build_scene → enhance_landscape → integrate_v4 → finalize_v4. integrate_v4는 기존 창구멍 생성 완료 컬렉션을 재생성하지 않는다. finalize_v4의 조명은 단일 적용용이다. road-surfaces-unioned.json은 OSM-derived geometry이며 원자료 출처/ODbL은 기존 LICENSES를 따른다.

## 무손실 파일 압축 검증
기본 Blender 압축18,335,088bytes를 Zstandard level19로10,645,347bytes로 줄였다. 압축 전후 해제된 전체 바이트의 SHA256은 `fe4844d695099f44ec761e789ab6b3aa4219641e3adeb55e1e715172ba4bff2f`로 같다. 압축본을 Blender5.2.4에서 재열어1754객체·무료수목12공유인스턴스·패킹텍스처·하늘키프레임 검증을 통과했다. 형상이나 텍스처를 제거하지 않았다.
